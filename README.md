# ML-Collision-Severity-YOLO-Detection

Examined datasets from the UK Road Safety Open Dataset and KITTI to predict collision severity via classification models (logistic regression, Random Forest, DNN).  Improved YOLO object detection performance through fine-tuning and customization of a pre-trained model for dashcam-based object detection.

Technologies Used:  Python, TensorFlow, scikit-learn, Ultralytics YOLO, EigenCAM
